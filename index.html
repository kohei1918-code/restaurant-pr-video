🎸 飲食店PRソング動画ジェネレーター

店舗URL＋6本の動画素材から30秒のPR動画を自動生成

動画処理はブラウザ内（ffmpeg.wasm）で完結します。素材は外部送信されません。歌詞・キャプション生成だけGoogle Gemini APIを使います（無料枠あり）。

① Google Gemini API Key（無料）

▶ APIキーの取得＆Google Cloud設定手順（初回のみ・10分）
  1. aistudio.google.com/apikey をクリック → Googleアカウントでログイン → 「APIキーを作成」 → AIza... の文字列をコピー → このページの上の入力欄に貼り付け
  2. Google Cloud Billingを有効化：console.cloud.google.com/billing で「請求先アカウントを作成」 → クレカ情報を登録 → 上で作ったAPIキーが紐づくプロジェクトにリンク
  3. 1〜2分待つと、APIが使えるようになります

クレカ登録は必要ですが、通常利用なら課金されません。Tier 1の無料枠（1分2,000リクエスト・1日数千〜数万リクエスト）に収まる限り$0です。新規ユーザーには$300のクレジットも自動付与されます。心配なら予算アラートで上限を設定してください。キーはこのブラウザにのみ保存され、外部送信されません。
